# Güvenlik Politikası

## Açık bildirme

Bir güvenlik açığı bulduysanız hassas ayrıntıları herkese açık issue, tartışma veya pull request içinde paylaşmayın.

GitHub üzerindeki [özel güvenlik açığı bildirim formunu](https://github.com/keremmalkann/taskavia/security/advisories/new) kullanın. Bildirime mümkünse etkilenen akışı, tekrar üretme adımlarını, beklenen etkiyi ve önerilen çözümü ekleyin.

Kimlik bilgileri, kişisel veriler veya gerçek kullanıcı verileri üzerinde izinsiz test yapmayın. Bir anahtarın açığa çıktığını düşünüyorsanız anahtarın kendisini bildirime eklemek yerine hangi sistemde bulunduğunu belirtin.

## Desteklenen sürümler

Proje aktif geliştirme aşamasındadır. Güvenlik düzeltmeleri yalnızca `main` dalının güncel sürümüne uygulanır.
